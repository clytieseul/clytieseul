Shopify Ecommerce Tracking

Enhanced ecommerce events • dataLayer consistency • attribution-ready

Overview

A Shopify ecommerce tracking implementation was delivered to accurately capture the purchase funnel, standardize dataLayer payloads, and improve attribution reliability across analytics and advertising platforms. The work focused on consistent event structure, complete product/variant parameters, and real-world validation using live product interactions.

Challenge

The store needed a reliable ecommerce measurement foundation. Key issues included inconsistent event payloads, missing ecommerce parameters, and limited confidence in product-level attribution—especially for variants and checkout steps.

  • Inconsistent or incomplete ecommerce event firing across PDP and checkout steps
  • Non-standard payload structure, making tags harder to map and maintain
  • Risk of inaccurate revenue, item, and variant attribution
  • Harder debugging due to unclear dataLayer formatting

Implementation Scope

  • Product detail view (PDP)
  • Variant selection tracking (ensuring item_variant consistency)
  • Add to cart and cart interactions
  • Checkout progression (begin checkout, shipping, payment)
  • Purchase / order confirmation

Approach

  • Standardized ecommerce naming and payload structure across events
  • Validated dataLayer pushes using browser Developer Tools and real user actions
  • Ensured product arrays included consistent identifiers (item_id / SKU, variant, price, quantity)
  • Kept payloads GTM-friendly and readable for long-term maintainability
Key outcome: Ecommerce events now share a consistent structure, making it easier to map to GA4 and ad platforms, and reducing attribution gaps caused by missing or malformed product data.

Sample Checkout Funnel dataLayer payloads

Below is an example using window.dataLayer. This structure mirrors a unique-style implementation while keeping event naming consistent and payloads easy to debug.

GTM-Compatible Sample Payloads
window.dataLayer = window.dataLayer || [];

let products = [];
let userProperties = {};

/** Base User Data Layer
 * Fire before all other events and on virtual page changes
 */
window.dataLayer.push({
  event: "dl_user_data",
  cart_total: "100.00",
  user_properties: userProperties,
  ecommerce: {
    currencyCode: "USD",
    cart_contents: {
      products: products
    }
  }
});

/** Begin Checkout */
window.dataLayer.push({
  event: "dl_begin_checkout",
  user_properties: userProperties,
  marketing: {
    landing_site: "/store/product-a?utm_source=web&utm_campaign=spring"
  },
  ecommerce: {
    currencyCode: "USD",
    checkout: {
      actionField: { step: "1" },
      products: products
    }
  }
});

/** Add Shipping Info */
window.dataLayer.push({
  event: "dl_add_shipping_info",
  marketing: {
    landing_site: "/store/product-a?utm_source=web&utm_campaign=spring"
  },
  user_properties: userProperties,
  ecommerce: {
    currencyCode: "USD",
    checkout: {
      actionField: { step: "2" },
      products: products
    }
  }
});

/** Add Payment Info */
window.dataLayer.push({
  event: "dl_add_payment_info",
  marketing: {
    landing_site: "/store/product-a?utm_source=web&utm_campaign=spring"
  },
  user_properties: userProperties,
  ecommerce: {
    currencyCode: "USD",
    checkout: {
      actionField: { step: "3" },
      products: products
    }
  }
});

/** Purchase */
window.dataLayer.push({
  event: "dl_purchase",
  marketing: {
    landing_site: "/store/product-a?utm_source=web&utm_campaign=spring"
  },
  user_properties: userProperties,
  ecommerce: {
    currencyCode: "USD",
    purchase: {
      actionField: {
        id: "4835925655784",
        order_name: "#1005",
        revenue: "185.3",
        tax: "15.3",
        shipping: "0.0",
        affiliation: "staging-fully-managed-ga4-all-events",
        sub_total: "170.0",
        product_sub_total: "170.0",
        discount_amount: "0.0",
        sales_channel: "pos",
        physical_location_id: "00000000000"
      },
      products: products
    }
  }
});
Tip: When mapping these events to GA4, translate dl_begin_checkout → begin_checkout, dl_add_shipping_info → add_shipping_info, dl_add_payment_info → add_payment_info, and dl_purchase → purchase.

Results & Impact

  • Standardized ecommerce payloads for dependable reporting and attribution
  • Improved product and variant consistency across PDP and checkout events
  • Simplified GTM/GA4 mapping with predictable event and ecommerce structures
  • Reduced debugging time with readable, console-verifiable dataLayer pushes
