GA4 + GTM Audit & Cleanup

Case Study

GA4 ecommerce event structure inside Google Tag Manager

Overview

A comprehensive Google Analytics 4 (GA4) and Google Tag Manager (GTM) audit was conducted to identify and resolve tracking inaccuracies caused by duplicate events, misfiring triggers, and inconsistent ecommerce implementation.

Challenge

The client’s analytics setup was producing unreliable data due to multiple implementation issues, making it difficult to trust reports and conversion metrics.

  • Duplicate GA4 ecommerce events firing across multiple pages
  • Events triggering on incorrect page types (e.g., list events on PDPs)
  • Non-standard and inconsistent GA4 ecommerce event naming
  • Overlapping GTM triggers inflating metrics
  • Unclear end-to-end conversion flow visibility

Audit Scope

The audit covered the full ecommerce and engagement funnel, including:

  • view_item_list, select_item, view_item
  • add_to_cart, view_cart, begin_checkout
  • add_shipping_info, add_payment_info, purchase
  • Subscription, login, email, and SMS engagement events

Actions Taken

  • Identified and eliminated duplicate GA4 event firing
  • Corrected trigger logic based on page type and dataLayer conditions
  • Standardized GA4 ecommerce event naming and parameters
  • Validated required ecommerce parameters (items, price, quantity, currency)
  • Tested the full user journey using GTM Preview Mode and GA4 DebugView
  • Cleaned and reorganized the GTM container for maintainability
Result: Each GA4 event now fires once per intended user action, with accurate parameters and correct sequencing across the entire funnel.

Results & Impact

  • Accurate ecommerce funnel tracking restored
  • Eliminated inflated metrics caused by duplicate events
  • Improved confidence in GA4 and marketing reports
  • Reliable conversion data for Google Ads and paid media platforms
